Vous gardez la main

Un bouton d'arrêt, des limites de perte journalière, un rapport clair de chaque position. Vous voyez tout, vous décidez tout.

On l'entretient

Les brokers et plateformes évoluent. Avec le webmastering, nous corrigeons et adaptons votre bot pour qu'il reste fiable.

Spécification formelle

Règles d'entrée/sortie, sizing, filtres de session et de volatilité formalisés en spec versionnée avant toute ligne de code.

Stack d'exécution

  • MQL5 (Expert Advisor MT5)
  • cTrader cBot (C#) / Pine Script + webhooks
  • Python (bridge MT5 / API broker REST-FIX)

Validation

  • Backtest tick-data + coûts réels (spread, swap, slippage)
  • Walk-forward & out-of-sample
  • Monte-Carlo sur séquence de trades
  • Forward test démo avant live

Risk engine & observabilité

  • Kill-switch, max drawdown jour/semaine
  • Contrôle d'exposition par symbole
  • Logs structurés + alertes (Telegram/email)
  • Code source livré, versionné Git
