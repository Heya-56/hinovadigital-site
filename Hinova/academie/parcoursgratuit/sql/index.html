SQL pour débutants

Toutes les entreprises gardent leurs clients, leurs ventes et leurs stocks dans des bases de données. SQL est le langage qui permet de leur poser des questions.

Niveau débutantEnviron 1 hExercices interactifs en ligne

Définition

C'est quoi, SQL ?

SQL (Structured Query Language) est le langage des bases de données. Une base de données range l'information dans des tables, comme des feuilles de calcul : chaque ligne est un enregistrement (un client), chaque colonne une information (son nom, sa ville).

Une requête SQL est une question posée à la base : « quels clients habitent à Dakar ? ».

Image simple : la base de données est une immense bibliothèque bien rangée. SQL, c'est la façon de demander au bibliothécaire exactement les livres que vous voulez.

Les notions clés

Cinq requêtes pour démarrer

  1. Tout afficher : SELECT

    Le point de départ de toute requête. L'étoile signifie « toutes les colonnes ».

    SELECT * FROM clients;

  2. Choisir les colonnes

    On peut demander uniquement les informations utiles.

    SELECT nom, ville FROM clients;

  3. Filtrer : WHERE

    On ne garde que les lignes qui respectent une condition.

    SELECT nom FROM clients
WHERE ville = 'Papeete';      -- Teva et Hina

  4. Trier : ORDER BY

    On range le résultat, du plus grand au plus petit avec DESC.

    SELECT nom, total_achats FROM clients
ORDER BY total_achats DESC;   -- Moussa en premier

  5. Compter et additionner

    SQL calcule directement : nombre de clients, total des ventes, regroupé par ville.

    SELECT ville, COUNT(*) AS nb_clients, SUM(total_achats) AS ca
FROM clients
GROUP BY ville;

Exercice

Répondez à trois questions de patron

Écrivez la requête avant de regarder la solution, puis testez-la dans un exercice SQL interactif en ligne.

  1. Quels clients ont acheté pour plus de 50 000 ? Solution : SELECT nom FROM clients WHERE total_achats > 50000;
  2. Quel est le meilleur client ? Solution : SELECT nom FROM clients ORDER BY total_achats DESC LIMIT 1;
  3. Combien de clients à Papeete ? Solution : SELECT COUNT(*) FROM clients WHERE ville = 'Papeete';

Pièges

Les erreurs de débutant

  • Oublier les guillemets autour du texteOn écrit ville = 'Dakar', mais total_achats > 50000 sans guillemets.
  • Modifier sans filtreUne commande de modification ou de suppression sans WHERE touche toutes les lignes de la table.
  • Oublier le point-virguleIl marque la fin d'une requête, surtout quand on en écrit plusieurs.
