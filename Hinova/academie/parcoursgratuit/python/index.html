Python pour débutants

Python est le langage le plus utilisé pour débuter en programmation. Il se lit presque comme de l'anglais et sert aussi bien à automatiser une tâche qu'à travailler avec l'IA.

Niveau débutantEnviron 1 h 30Testable en ligne, sans installation

Définition

C'est quoi, Python ?

Python est un langage de programmation : il donne des instructions à l'ordinateur, qui les exécute dans l'ordre. Contrairement à HTML, il peut calculer, prendre des décisions et répéter des actions.

Image simple : un programme Python est une recette de cuisine. Les ingrédients sont les données, les étapes sont les instructions, et l'ordinateur est le cuisinier qui suit la recette à la lettre.

À quoi ça sert

Ce que Python fait pour un entrepreneur

Automatiser

Renommer cent fichiers, envoyer des relances, remplir un tableau chaque matin.

Analyser

Lire un fichier de ventes et en sortir les meilleurs produits du mois.

Travailler avec l'IA

La plupart des outils d'intelligence artificielle se pilotent avec Python.

Les notions clés

Cinq notions pour démarrer

  1. Afficher un message

    La première instruction de tout débutant : demander à l'ordinateur d'écrire quelque chose.

    print("Ia ora na !")

  2. Les variables

    Une variable est une boîte avec une étiquette, dans laquelle on range une valeur pour la réutiliser.

    produit = "Panier tressé"
prix = 4500
print(produit, "coûte", prix, "XPF")

  3. Les conditions

    Le programme choisit quoi faire selon la situation, avec if (si) et else (sinon).

    stock = 2
if stock < 5:
    print("Penser à recommander")
else:
    print("Stock suffisant")

  4. Les listes et les boucles

    Une liste range plusieurs valeurs. Une boucle répète une action pour chacune.

    ventes = [4500, 12000, 3000]
for montant in ventes:
    print("Vente :", montant)
print("Total :", sum(ventes))

  5. Les fonctions

    Une fonction regroupe des instructions sous un nom, pour les réutiliser autant de fois que nécessaire.

    def prix_ttc(prix_ht, taux):
    return prix_ht * (1 + taux / 100)

print(prix_ttc(10000, 16))   # affiche 11600.0

Attention : en Python, le décalage du texte vers la droite (l'indentation) fait partie du langage. Il indique ce qui appartient à une condition, une boucle ou une fonction.

Exercice

Votre premier programme utile

Un éditeur Python en ligne gratuit suffit : aucune installation n'est nécessaire, même sur téléphone.

  1. Ouvrez un éditeur Python en ligne.
  2. Créez une liste avec les montants de vos cinq dernières ventes.
  3. Affichez le total, puis la moyenne avec sum(ventes) / len(ventes).
  4. Ajoutez une condition : si la moyenne dépasse un objectif, affichez « Objectif atteint ».
  5. Transformez le tout en fonction, et testez-la avec d'autres listes.

Pièges

Les erreurs de débutant

  • Oublier les deux-pointsUne ligne if, for ou def se termine toujours par :.
  • Mélanger texte et nombre"4500" entre guillemets est du texte : on ne peut pas l'additionner sans le convertir avec int().
  • Décaler de traversUn décalage irrégulier provoque une erreur d'indentation. Gardez toujours quatre espaces.
