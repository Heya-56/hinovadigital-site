HTML & CSS pour débutants

Toutes les pages web reposent sur deux langages. HTML écrit le contenu, CSS l'habille. En une heure, vous pouvez créer votre première page.

Niveau débutantEnviron 1 hFaisable sur téléphone

Définition

C'est quoi, HTML et CSS ?

HTML (HyperText Markup Language) est le langage qui décrit le contenu d'une page : titres, paragraphes, images, liens. Ce n'est pas un langage de programmation : il ne calcule rien, il structure.

CSS (Cascading Style Sheets) décide de l'apparence de ce contenu : couleurs, polices, tailles, placement à l'écran.

Image simple : HTML, ce sont les murs et les pièces d'une maison. CSS, c'est la peinture, la décoration et l'agencement des meubles.

Les notions clés

Cinq notions pour démarrer

  1. Les balises

    HTML entoure chaque contenu d'une balise ouvrante et d'une balise fermante. Elles indiquent la nature du contenu.

    <h1>Bienvenue dans ma boutique</h1>
<p>Des paniers tressés à la main.</p>

  2. La structure d'une page

    Une page a toujours la même ossature : une tête (informations invisibles) et un corps (ce que l'on voit).

    <!DOCTYPE html>
<html lang="fr">
  <head>
    <meta charset="UTF-8">
    <title>Ma première page</title>
  </head>
  <body>
    <h1>Bonjour !</h1>
  </body>
</html>

  3. Liens et images

    Certaines balises ont des attributs : l'adresse d'un lien, le fichier d'une image et sa description.

    <a href="https://hinovadigitalcorp.com">Visiter le site</a>
<img src="panier.jpg" alt="Panier en pandanus">

  4. Le sélecteur et la règle CSS

    En CSS, on choisit un élément (le sélecteur), puis on lui donne des propriétés.

    h1 {
  color: #1B64C8;      /* couleur du texte */
  font-size: 32px;     /* taille */
}

  5. Les classes

    Une classe permet d'habiller plusieurs éléments de la même façon, sans tout répéter.

    <p class="prix">4 500 XPF</p>

.prix { font-weight: bold; color: #B5823A; }

Exercice

Votre première page en 10 minutes

Vous pouvez le faire sur un ordinateur ou dans un éditeur de code en ligne gratuit, depuis votre téléphone.

  1. Ouvrez un éditeur de texte simple, ou un éditeur de code en ligne.
  2. Copiez la structure de la notion 2 ci-dessus.
  3. Remplacez « Bonjour ! » par le nom de votre activité, et ajoutez un paragraphe qui la décrit.
  4. Ajoutez dans la tête une balise <style> avec une règle qui colore votre titre.
  5. Enregistrez le fichier sous le nom index.html et ouvrez-le dans votre navigateur.

Pièges

Les erreurs de débutant

  • Oublier de fermer une baliseLa suite de la page prend alors le style de la balise restée ouverte.
  • Oublier le texte alternatif des imagesL'attribut alt décrit l'image aux personnes malvoyantes et aux moteurs de recherche.
  • Mettre la mise en forme dans le HTMLGardez le contenu en HTML et l'apparence en CSS : la page sera plus simple à modifier.
